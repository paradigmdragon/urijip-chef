# 연결 구조

## 현재 구조

- 손잡고 프로젝트 #72: 목적·설계·참여·작업 결과의 연결점.
- 이 GitHub 저장소: 디자인 소스와 협업 문서·수정 검토의 기준.
- 기존 Sites: 별도 관리 소스로 배포된 디자인 시연 화면. 이 저장소와 자동으로 동기화되지 않음.
- 기존 손잡고 웹 `/chef`: 기존 인증과 개인 Sondocs를 사용하는 별도 구현.

## 검토 중인 목표

사용자는 Sites DB를 셰프 재고의 원본으로 두고 손잡고 앱·모듈을 통해 일반 채팅에서도 같은 데이터를 관리하는 구조를 제안했습니다. 이는 아직 구현이 아닙니다.

먼저 Sites의 실제 저장 기능, 서버 호출 경로, 방문자별 권한, 손잡고 계정과의 명시적인 연결을 검증해야 합니다. 두 저장소에 같은 재고 전체를 복제해 각각 수정하는 방식은 우선하지 않습니다. 동기화가 꼭 필요한 항목만 원본·버전·변경 식별자·중복 방지·충돌 처리와 함께 정합니다.

인증 토큰을 브라우저 소스에 넣거나, 공개 저장소에 개인 데이터를 저장하거나, 서로 다른 계정을 임의로 연결하지 않습니다. GitHub 협업 권한과 실제 서비스의 사용자 데이터 접근 권한은 별개입니다.
