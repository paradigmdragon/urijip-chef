# 구현 점검과 재사용 검토 — 2026-11-04

## 결론

현재 Sites는 디자인 시연 단계다. 첫 개발은 동일한 소유자 기록을 화면과 채팅에서 읽고 확인·수정·재접속할 수 있는 가장 작은 흐름으로 한다. 사이트 DB를 원본으로 하려는 최근 제안은 유효한 후보지만, 원본 전환과 기존 기록 이관은 아직 실행되지 않았다.

## 우선순위와 완료 조건

### 1. 저장과 채팅 접근 경로 검증

후보 A: Sites의 기존 로그인 + D1/R2 + 사이트 자체 MCP를 사용한다. 기본 로그인·저장 기능·공식 starter를 재사용하고 임의 OAuth 서버를 만들지 않는다. 사이트 자체 MCP 연결과 손잡고 앱 통합은 별개다.

후보 B: 기존 손잡고 웹/Sondocs 경로를 유지해 먼저 핵심 기능을 다듬는다. 현재 즉시 재사용할 구현이 있으나 Sites DB 원본화 목표와 다르다.

후보 A를 먼저 작은 격리 시험으로 검증하는 것을 권고한다. 공식 Sites 지침에는 DB와 Site MCP 경로가 있지만, 현재 사이트에서 실제 실행된 것은 아니다. 사이트 ID·공개 범위는 보존하고, 익명 API는 개인 기록에 접근할 수 없어야 한다.

완료 조건: 사용자 A 수동 등록→저장→새 접속 유지→동일 사용자 MCP 조회→명시적 수정→화면 재조회. 사용자 B 읽기/수정 거부. 중복 요청·오래된 버전·동시 수정 처리. 사이트 범위 ID와 손잡고 ID는 별도이며 명시적인 연결 없이 같다고 가정하지 않는다. 서비스 접근 토큰은 사용자 신원과 연결 동의를 대신하지 않는다.

### 2. 확인·수정 중심의 수동 재고

기존 손잡고의 구매분별 lot, 수량/단위, 유통기한/소비기한 분리, 미확인 값, preview/apply·변경 식별자·이력·재조회 경험을 재사용한다. 현재 소스/테스트/권한 계약을 다시 대조하고 필요한 부분만 이식한다. 기한 알림 전에는 먼저 소유자별 재고와 기록 이력이 일치해야 한다.

### 3. 사진·영수증 분석 비교 시험

가상 또는 사용 허용된 한국어 영수증·포장 사진을 동일 조건으로 비교한다. OCR 문자 인식과 품목/수량/가격/날짜 의미 추출을 별도로 평가한다. 사용자가 확인하기 전에는 재고를 변경하지 않는다. 냉장고 속 비문자 식재료는 OCR로 식별할 수 없으므로 이미지 이해 기능을 별도로 검증한다.

### 4. 제품 정보 보강

바코드가 있는 포장 식품에 Open Food Facts 후보를 검증한다. 한국 상품 조회 적중률, 한국어명, 미등록 처리, 원재료 최신성, 데이터 출처를 표본으로 확인한다. 바코드 정보는 개별 구매분의 소비기한·수량·실제 알레르기 안전성을 증명하지 않는다.

### 5. 레시피·알림·예산

재고 정확성과 계정 경계를 확보한 뒤 Mealie API의 조리법/식단/장보기 재사용을 검토한다. 소비 완료 수량은 확인받고 반영한다. 알림은 백그라운드 실행·도달 지원을 검증한 후 연결한다. 품앗이 퀘스트의 현재 계약 확인 없이 새 큐/작업 엔진을 만들지 않는다.

## 개발지침 적용과 판단 재검토

손잡고의 프로젝트작업관리, 능력선택재사용, 기준판단검증, 부정전제검증과 현행 손잡고개발지침을 조회했다. 이 저장소 `AGENTS.md`에 프로젝트별 실행 기준을 반영했다. 원본 개인 지침 전문·개인 기록은 공개 문서에 복제하지 않는다.

- 부정의 생략: 과거의 “새 DB 없이 연결”만 남기면 최근의 “Sites DB 원본화” 제안을 지우게 된다. 기존 Sondocs는 보존하면서 원본 전환 후보를 평가한다. Grocy/Mealie 전체 도입을 당장 선택하지 않은 이유는 별도 런타임·계정·저장소 운영이 늘기 때문이다. 영구 배제로 해석하지 않는다.
- 부재된 전제: Sites 로그인 성공, 연결된 손잡고 계정과의 동일성, 자체 MCP 발급·동의, 사용자 격리, 런타임 호환, 한국어 OCR 정확도, 데이터 라이선스 준수는 미검증 조건이다. 문서상 지원을 현재 사이트 성공으로 바꾸지 않는다.
- 부정의 잔상: 현재 제공되지 않는 적격성 확인 도구만으로 모든 연결이 불가능하다고 단정하지 않는다. 사이트 자체 MCP와 앱 호출 방향을 분리한다. 적격성 도구 미제공을 관리자 거부로 보지 않는다.
