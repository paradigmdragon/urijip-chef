## 현재 들어 있는 것

`web/`는 Sites v1에서 사용한 한국어·모바일 우선 디자인 원본입니다. 홈·내 냉장고·레시피·장보기·우리 가족 화면, 명시적인 가상 예시 보기, AI 채팅 요청 복사를 제공합니다.

**이 소스 자체에는 로그인, 실제 재고 저장·조회, 사진 AI 분석, 자동 알림이 연결되어 있지 않습니다.** 손잡고 웹에서 검증한 재고 연결 구현은 별도 손잡고 저장소에 있습니다. 두 구현을 혼동하지 않습니다.

## 로컬에서 보기

Python 3만 있으면 됩니다. 별도의 패키지 설치나 API 키는 필요 없습니다.

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory web
```

브라우저에서 `http://127.0.0.1:8080`을 엽니다. 확인 후 터미널에서 Ctrl+C로 서버를 종료합니다.

기본 검사에는 Node.js 18 이상을 사용합니다.

```sh
node scripts/check-site.mjs
```

GitHub 자동 검사는 아직 활성화하지 않았습니다. 현재 연결의 workflow 쓰기 권한 부족으로 [설정 예제](docs/ci/source-checks.example.yml)만 보관하며, 위 명령은 로컬에서 실행할 수 있습니다.

## 함께 만드는 방법

코딩을 몰라도 손잡고 프로젝트에서 불편한 점, 개선할 문구, 화면 설계, 사용 시나리오를 제안할 수 있습니다. 코드 변경은 GitHub Issue와 Pull Request로 검토합니다. 품앗이 퀘스트가 준비되면 해당 작업 주소를 Issue·PR에 연결합니다. 현재 자동 연결 기능은 없습니다.

개인 재고·가족 건강정보·실제 영수증·인증정보는 공개 저장소와 Issue에 올리지 않습니다. 시연 자료는 가상 데이터로 작성합니다.

## 배포

이 저장소는 협업용 소스 저장소입니다. **GitHub main에 반영하는 것과 운영 Sites 배포는 별도 단계이며, 자동 동기화·자동 배포는 설정하지 않았습니다.** 기존 사이트와 DB를 변경하지 않고 검토·검증 후 담당자가 명시적으로 배포합니다. 자세한 절차는 [배포 안내](docs/DEPLOYMENT.md)를 참조하세요.
